# 떨사오팔 주문표

https://jabcho10.github.io/ddsop-order/

떨사오팔 Pro(Pro1/2/3) 분할 LOC 매매의 오늘 주문을 계산하는 페이지입니다.

- **오늘 낼 주문**: 보유 티어와 전일 종가로 매수·매도 LOC 주문과 손절 MOC 주문을 계산합니다.
- **자동 추천 전환**: 티어가 모두 비어 있으면, 마지막으로 반영한 날 종가로 낸 추천 전략으로 자동으로 바꿉니다. 사이클이 진행되는 동안에는 전략을 고정합니다.
- **종가 반영**: 반영하지 않은 종가를 한 번에 반영할 수 있고, 거래일을 고르면 종가가 자동으로 채워집니다.
- **저장**: 상태는 브라우저(localStorage)에 저장합니다. 다른 기기에서 쓰려면 백업 파일을 받아 옮기세요.

`data/latest.json`(거래일별 종가와 추천)은 평일 미국 장 마감 후 자동으로 갱신됩니다.

학습·참고용이며 투자 권유가 아닙니다.
